BUS 340 – AI vs. Traditional Marketing


Files

- BUS 340 AI vs Traditional Dashboard.pbix – Power BI dashboard containing the interactive visualizations and statistical calculations
- BUS 340 Project DAX Measures.txt – DAX measures used in Power BI
- BUS 340 Project M Code Power BI text file – Code used to import and transform the dataset
- AI vs. Traditional Advertisement Survey – Survey responses used for the analysis

Setup Instructions

1. Download the Power BI dashboard and Excel survey dataset
2. Open BUS 340 AI vs Traditional Dashboard.pbix Power BI file
3. In Power BI Desktop, go to "Home → Transform data → Data source settings" **These steps are only necessary if data needs to be refreshed or data import needs to be reproduced
4. Select the Excel data source and choose "Change Source"
5. Browse to the downloaded Excel survey dataset and confirm the new file location
6. Select "Close & Apply" 

Run Instructions

1. In Power BI Desktop, select "Home → Refresh" to reload the survey data
2. Open "Campaign Overview" to compare average survey ratings between the two advertisement groups
3. Open "Hypothesis Test Results" to view the t-statistic, degrees of freedom, p-value, and hypothesis decision
4. Use the age group, AI familiarity, and purchase frequency filters to explore how the statistical results change
5. Open "Consumer Segment Analysis" to compare purchase intention across respondent categories

Supporting Code

The DAX measures "BUS 340 Project DAX Measures" and Power Query(M) script "BUS 340 Project M Code Power BI" text files are for reviewing calculations and data prep steps
